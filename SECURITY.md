# Security Policy

## Supported versions

Security fixes are applied to the current `develop` branch. Production releases
are cut from `main`; users should upgrade to the latest release when a fix is
available.

## Reporting a vulnerability

Please report potential vulnerabilities privately through the repository's
GitHub Security Advisories page rather than opening a public issue. Include a
clear reproduction, affected version or commit, impact, and any suggested
mitigation. We will acknowledge reports within seven days and coordinate a fix
and disclosure timeline with the reporter.

Do not include credentials, customer data, or exploit payloads in public issues.
